# LANCHROM™ Product Specification Summary

## 1. Specification scope

- Product
- CAS number
- Grade scope
- Document status: Reference specification summary

## 2. Test requirements

| Test item | Specification / reference value | Test method |
|---|---|---|
| Identification | Approved product reference | Approved method |
| Appearance | Grade-specific controlled specification | Visual / approved method |
| Assay / purity | Grade-specific controlled limit | Approved method |
| Water | Grade-specific controlled limit | Karl Fischer / approved method |
| Residue | Grade-specific controlled limit | Approved method |

有确认的产品参数时替换通用项目。不得为填满表格而编造数值。

## 3. Packaging and release documents

- 合并所有包装尺寸。
- 每批以 batch COA 为放行数据。
- 采购和验证前索取 current approved specification。
