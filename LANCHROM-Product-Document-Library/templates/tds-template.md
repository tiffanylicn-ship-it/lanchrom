# LANCHROM™ Technical Data Sheet

## Document control

- Document ID
- Revision
- Issue date
- Product line / category

## 1. Product identity and grade scope

- Product name
- CAS number
- Molecular formula
- Molecular weight
- Available grades
- Product category

## 2. Product overview and applications

- Short technical description
- Recommended applications
- Application qualification note

## 3. Physical and handling information

- Appearance
- Density / boiling point / flash point（仅在有确认数据时）
- Storage conditions
- Shelf life

## 4. Consolidated packaging options

同一产品的所有包装尺寸放在一份表格中，列出容量、容器、供应状态。不要因包装尺寸重复生成 TDS。

## 5. Safety and documentation

- UN / hazard class（以当前 SDS 为准）
- TDS / Specification / SDS / batch COA 可用状态
- Reference Summary 声明
