# 文件治理与欧洲市场规则

## 文件分层

| 文件 | 是否公开下载 | 更新触发 | 注意事项 |
|---|---:|---|---|
| TDS | 是 | 产品信息、用途、包装、储存变化 | 可合并所有包装尺寸 |
| Product Specification Summary | 是 | 规格项目或参考值变化 | 多等级时明确限值可能按等级不同 |
| Current Approved Specification | 否 | 受控变更 | 由质量或技术部门提供批准版本 |
| COA | 否，按批次提供 | 每批生产与放行 | 必须包含实际批次结果，不得用模板替代 |
| SDS | 按市场提供 | 分类、法规、用途、供应商信息变化 | 16 章节；目的国语言；REACH / CLP 信息需复核 |

## 欧洲客户资料包

1. 产品 TDS。
2. Product Specification Summary。
3. Representative COA（资格审查阶段）。
4. Batch COA（实际交付批次）。
5. 当前 SDS，按目的市场语言提供。
6. 标签资料：产品标识、CAS、EC（适用时）、批次、日期、净含量、供应商与危险信息。
7. 运输资料：UN、危险类别、包装组及 ADR / IMDG 信息（适用时）。

## 变更控制

以下变化需要评估是否重新生成文件或通知客户：

- 生产或检测地点变化。
- 产品规格、检测方法或等级变化。
- 原料或关键净化工艺变化。
- 包装材料、封口、容量或标签变化。
- SDS 分类、暴露控制或运输信息变化。
- 公司名称、地址、欧洲供应链角色变化。
