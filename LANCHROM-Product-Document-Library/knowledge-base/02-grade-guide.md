# 产品等级说明

| 等级 | 主要用途 | 客户最关注参数 | 资料表达方式 |
|---|---|---|---|
| HPLC Isocratic | 固定比例流动相、常规 HPLC | UV cutoff、purity、water、residue | HPLC Grade / Isocratic suitability |
| HPLC Gradient | 梯度洗脱、杂质方法 | 梯度基线、UV 吸收、杂质峰 | Gradient-tested；不得只写 HPLC Grade |
| HPLC Prep | 制备色谱、大体积纯化 | 纯度、成本、批次稳定性、包装 | Preparative Grade；列出 20 L / 200 L / IBC |
| LC-MS | 生物分析、蛋白组、药物研究 | MS background、ion suppression、non-volatile residue、metals | LC-MS Grade；必须与普通 HPLC 区分 |
| UPLC | 超高压、小粒径色谱柱 | 颗粒、过滤、背景 | UPLC Grade / ultra-low particulate |
| GC | GC / GC-MS | 挥发性杂质、残留峰 | GC-tested |
| Pharma | 制药工艺和药典相关用途 | 药典适用性、杂质、文件、变更 | 仅在有依据时写 USP / EP，不自动等同 GMP |
| G2-G5 | 电子和半导体材料 | 金属离子、颗粒、水分、工艺稳定性 | 写明具体等级和适用工艺，不笼统写 ultra-pure |
| Anhydrous | 水敏反应和材料处理 | Water、包装、开封管理 | Anhydrous Grade；写明受控水分限值来源 |
| AR / GR | 常规分析、合成、萃取 | Assay、impurities、residue | Analytical Reagent / Guaranteed Reagent |

## 重要限制

- “High purity”是定位，不是完整规格。
- “Pharma”不能自动解释为药典符合、GMP 生产或可用于注射剂。
- “REACH compliant”“RoHS compliant”等声明必须基于实际注册、供应链角色和产品文件。
- 公开下载规格书是 Reference Summary；批准规格以受控文件为准。
