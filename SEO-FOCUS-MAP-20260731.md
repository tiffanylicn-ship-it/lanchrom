# LANCHROM single-topic SEO focus

Updated: 2026-07-31

## Rule used

Each indexable page or dynamic page template has one primary search intent. Titles and H1 headings identify that topic; supporting copy explains it naturally without exposing keyword lists. Explicit `keywords` metadata, where present, contains no more than one phrase.

Google does not use the historical `meta keywords` tag as a ranking signal. The practical ranking work in this revision is therefore concentrated in focused titles, descriptions, H1 headings, canonicals, internal links, useful page content, and the removal of visible SEO-specification text.
